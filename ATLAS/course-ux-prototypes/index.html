Decisions we need

The prototypes assume an answer to each of these. A different answer changes the design, so please confirm before this goes further.

  • Content problems found in production

    The quiz scores A, A, A, A as 4/4, yet Question 1's option A ("tennis shoes … high bounce rate") contradicts its scenario. The course card says 180m where the course page says 1h 5m. Recommend: ask the content team to check both.

  • What does adaptive learning change?

    Skipped or optional lessons, extra lessons, or a different order? The path view shows an optional lesson as a sample only. Recommend: confirm so the markers match real behaviour.

  • Lesson review pass mark

    80% of three questions means all three correct (two of three is 67%). Recommend: lower the mark or add questions.

  • Quiz pass mark and finishing

    Production shows only a score. The prototype uses 75% (3 of 4) and unlocks "Finish course" on a pass. Recommend: confirm both.

  • Free or sequential navigation?

    The outline lets learners open any lesson; Next still waits for the review. Recommend: keep it free, since adaptive paths differ per learner.

  • Where do exercise answers go?

    The persona exercise now takes input in the page. It is stored in the browser only. Recommend: save to the learner's record so a coach can see it.

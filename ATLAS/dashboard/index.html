Learner dashboard — eight design directions

Eight redesigns of demo.atlaslearn.ai/dashboard, each built against a different design system from designmd.co. Same content and the same six destinations in every option; the layout is free to follow whatever that system's logic demands.

Desktop-first — view at 1280px or wider Returning-learner state Static HTML, dummy data

Option 01

Notion

Colourful and warm. The strongest answer to “the greyish is dull”.

  • Navy hero band with sticky-note dot decoration
  • White card breaks out of the band — Notion's signature move
  • Six pastel-tinted tool cards instead of six identical white ones
  • Bold-yellow Jen banner with a chat mockup

Option 02

Stripe

Serious and premium. Colour comes from atmosphere, not from cards.

  • Gradient mesh washed across the upper third
  • Thin 300-weight display type with tight negative tracking
  • Tabular figures on every number — the financial-data signal
  • Practice question shown as a dark-navy product mockup
Open option Curated system

Option 03

Apple

Slow, spacious, one thing at a time. Reads like a product launch page.

  • Full-bleed tiles alternate light → near-black → parchment → dark
  • The colour change is the only section divider — no borders
  • Exactly one accent blue and exactly one shadow on the page
  • Frosted sticky sub-nav with a persistent Resume button
Open option Curated system

Option 04

Vercel

Stark and modern. Directly attacks the “quiz is too boring” note.

  • Mesh gradient plus gradient headline text
  • Monospace carries every label and every number
  • Practice question rendered as a dev console on a black band
  • Stacked hairline shadows — cards sit, never float
Open option Curated system

Option 05

OpenAI

The quietest of the six. Typography does all the work.

  • Persistent sidebar plus a single centred reading column
  • An “ask Jen” composer sits where the hero normally would
  • No shadows, one 5px radius, one muted accent
  • Included as a deliberate contrast point, not a front-runner
Open option Measured extraction

Option 06

Anthropic

Warm, editorial, high contrast. Two colours doing a lot of work.

  • Warm cream canvas — not grey, not cold white
  • Hard 1px near-black rules instead of soft card borders
  • 58px editorial display headline
  • One large near-black block carries the whole Today section
Open option Measured extraction

Option 07

ElevenLabs

Editorial and calm. The only option in the set that uses a serif.

  • Light serif display at weight 300 — print-magazine voice
  • Pastel gradient orbs drift behind the page as pure atmosphere
  • No saturated accent at all; the CTA is a plain ink pill
  • 96px section rhythm, one soft shadow tier, nothing more
Open option Curated system

Option 08

Cohere

Enterprise command centre. Monumental type, deep product bands.

  • Huge mono-spirited headline over open white space
  • Hero is a two-card split: wide product card beside a stat card
  • Full-width deep-green and dark-navy bands carry the product
  • Rows and rules instead of cards; coral used only for tagging
Open option Curated system

Read before reviewing

  • Two of the eight are not curated systems. Notion, Stripe, Apple, Vercel, ElevenLabs and Cohere have full DESIGN.md specs on designmd.co — tokens, component definitions, do's and don'ts. OpenAI and Anthropic are automated extractions: OpenAI supplies four colours, three type roles, one 5px radius and no shadows; Anthropic supplies two colours and a single 58px display tier. Options 05 and 06 are built faithfully to that, so they are quiet by construction, not by neglect.
  • Fonts are substitutes where the real face is proprietary. Sohne (Stripe), SF Pro (Apple), Notion Sans, Anthropic Sans, Waldenburg (ElevenLabs), CohereText and Unica77 cannot be licensed here — each option uses the fallback its own DESIGN.md names. Geist and Geist Mono (Vercel) are open source and load for real. Option 03 will look closest to the reference on a Mac.
  • Every option shows a returning learner — 80% through a course, a 12-day streak, 1,240 XP, per-topic mastery. The live dashboard is a brand-new-account empty state (0/0 knowledge points, 0/1 badges, three features described as “unlocks later”), which is a large part of why it reads flat. If the new-user view is what needs redesigning, that is a separate exercise.
  • PALS and CBL keep their existing names in all eight, with the expansion added underneath as a plain-language line. Renaming them is still an open question.
